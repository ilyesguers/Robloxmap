# 🤖 بوت تيليجرام — زيادة لايكات فري فاير (Free Fire Likes Bot)

بوت تيليجرام كامل (Python + aiogram 3 + aiohttp) يعمل كمحرك آلي لإرسال
الإعجابات إلى بروفايلات فري فاير (Garena) عبر إنشاء **حسابات ضيوف مؤقتة**
واستخراج **توكنات الجلسة** واستخدامها لإرسال الإعجاب للـ UID المستهدف
حتى الوصول للحد اليومي — بدون أي إنشاء حسابات يدوي.

---

## ⚠️ تنبيهات مهمة — اقرأها أولاً

1. **مخالفة لشروط Garena:** الأتمتة وإنشاء حسابات الضيوف البرمجية مخالفة
   لشروط خدمة اللعبة. الاستخدام على مسؤوليتك الخاصة، وقد تواجه حظر IP
   أو حظر حسابات.
2. **الروابط في الكود PLACEHOLDERS:** واجهات Garena الداخلية غير موثقة
   رسمياً وتتغير باستمرار وتتطلب توقيع (signature) مطابقاً لعميل اللعبة
   الحالي. **لا يمكن للكود العمل فوراً** — يجب التقاط الروابط والخوارزميات
   الحالية من حركة عميل اللعبة (MITM / Frida / تفكيك APK) ووضعها في
   متغيرات البيئة.
3. **البروكسيات ضرورية:** توليد عدة حسابات ضيوف من IP واحد يفعّل أنظمة
   مكافحة السبام — استخدم بروكسيات دوّارة (HTTP/SOCKS5) موثوقة.
4. هذا المشروع **لأغراض تعليمية/بحثية** في هندسة البوتات والواجهات.

## 🔄 تدفق العمل التقني (The Core Flow)

```
المستخدم يرسل UID
      │
      ▼
┌─────────────────────┐
│ LikeEngine (صف انتظار) │
└──────────┬──────────┘
           ▼  حلقة حتى MAX_LIKES_PER_SESSION
┌──────────────────────────────────────────────┐
│ 1. ProxyRotator → اختيار بروكسي جديد (HTTP/SOCKS5) │
│ 2. بناء رؤوس جهاز (iPhone 13 / Android عشوائي)     │
│ 3. POST guest/register → حساب ضيف جديد            │
│ 4. استخراج Access Token / Session Key من JSON     │
│ 5. POST like/send مع التوكن → إعجاب للـ UID        │
│ 6. فحص الرد: حد يومي؟ ← إيقاف فوري + إشعار المستخدم │
│    نجاح؟ ← عدّ + إرسال تحديث كل PROGRESS_EVERY     │
│    فشل شبكة؟ ← إعادة محاولة بتراجع (backoff)       │
└──────────────────────────────────────────────┘
           ▼
🏁 إشعار نهائي + حفظ الإحصائيات في SQLite
```

## ☁️ النشر على Railway مجاناً (من الآيفون — بدون كمبيوتر)

> المتطلبات: حساب GitHub + حساب Railway (تسجيل عبر Google/Apple مباشرة من Safari).

1. **على هاتفك:** افتح GitHub ← ادمج الـ Pull Request (الملفات موجودة جاهزة).
2. افتح [railway.app](https://railway.app) وسجّل (يمنحك رصيد تجريبي مجاني).
3. اضغط **New Project** ← **Deploy from GitHub repo** ← اختر هذا المستودع.
4. انتظر البناء (Nixpacks يكتشف Python تلقائياً — يوجد `Procfile` و`railway.json`).
5. افتح تبويب **Variables** وأضف:
   | المتغير | القيمة |
   |---|---|
   | `BOT_TOKEN` | من [@BotFather](https://t.me/BotFather) |
   | `ADMIN_ID` | معرّفك الرقمي (من [@userinfobot](https://t.me/userinfobot)) |
   | `GUEST_REGISTER_URL` | رابط التسجيل الفعلي |
   | `GUEST_LOGIN_URL` | رابط تأكيد الدخول (اختياري) |
   | `LIKE_URL` | رابط الإعجاب الفعلي |
   | `SIGN_SECRET` | سر التوقيع (إن وجد) |
   | `PROXIES` | قائمة بروكسيات مفصولة بفواصل |
   | `PROXY_API_URL` | أو رابط API بروكسيات دوّارة |
   | `MAX_LIKES_PER_SESSION` | الحد الأقصى (مثلاً 100) |
6. عد إلى **Deployments** ← **Redeploy** ثم افتح **View Logs** للتأكد
   من ظهور `🚀 البوت يعمل الآن...`.
7. افتح البوت في تيليجرام وأرسل `/start`. ✅

> 💡 ملاحظة: على الخطة المجانية، Railway قد يوقف التطبيق بعد فترة خمول
> — التطبيق يعيد التشغيل تلقائياً عند وصول أي تحديث من تيليجرام
> (polling يبقي الاتصال نشطاً). بدائل مجانية: Koyeb، Render (مع webhook).

## 🧰 أوامر البوت

### للمستخدمين
| الأمر | الوصف |
|---|---|
| `/start` | القائمة الرئيسية (أزرار تفاعلية) |
| `/likes <UID>` | بدء طلب إعجابات بسرعة |
| `/cancel` | إلغاء المهمة الحالية |
| أزرار القائمة | إرسال لايكات / إحصائياتي / المساعدة |

### للأدمن (صاحب ADMIN_ID فقط)
| الأمر | الوصف |
|---|---|
| `/stats` | إجمالي المستخدمين/الطلبات/الإعجابات/المحظورين + حجم الصف |
| `/broadcast <نص>` | رسالة جماعية لكل المستخدمين |
| `/ban <user_id> [سبب]` | حظر مستخدم |
| `/unban <user_id>` | فك الحظر |
| `/queue` | حالة قائمة الانتظار |
| `/clear_queue` | مسح كل المهام المعلقة |

## 🔧 قبل التشغيل الفعلي: ماذا يجب أن توفر؟

1. **الروابط الحقيقية** لـ `GUEST_REGISTER_URL` / `GUEST_LOGIN_URL` / `LIKE_URL`.
2. **خوارزمية التوقيع** المطابقة للعميل الحالي (في `_compute_sign` داخل `services/api_client.py`).
3. **شكل الاستجابة** (أسماء الحقول) لاستخراج التوكن والكود — الكود يستخدم
   `_deep_find` ليتحمل أسماء حقول متعددة.
4. **بروكسيات دوّارة** جاهزة (بدونها سيتم حظر IP بسرعة).

> 💡 نصيحة: ركّز أولاً على تشغيل `FFAPIClient` في سكربت تجريبي صغير،
> وتحقق من استجابة التسجيل والتوكن، ثم شغّل البوت كاملاً.
